# Kriti's Gamified Portfolio 🎮

Welcome to my professional multiverse. This project is a high-impact, full-stack portfolio that combines traditional resume elements with an immersive arcade experience.

## 🚀 Quick Start

### 1. Requirements
- Node.js v18+
- MongoDB Account (optional, has fallback)

### 2. Installation
```bash
# Clone the repo
git clone <your-repo-link>

# Setup Frontend
cd client
npm install
npm run dev

# Setup Backend
cd ../server
npm install
npm run dev
```

### 3. Environment Setup
Create a `.env` in the `server` folder:
```env
PORT=5000
MONGO_URI=your_mongodb_uri
EMAIL_USER=your_email@gmail.com
EMAIL_APP_PASS=your_gmail_app_password
```

## 🌟 Key Features
- **Dual-Mode UI**: Switch between Classic and Game mode.
- **Custom Game Engine**: 60fps performance with collision and combat.
- **Integrated Contact System**: Direct email notifications via Nodemailer.
- **Interactive Achievements**: 3D verified certificates wall.

## 🛠️ Tech Stack
- **Frontend**: React, Framer Motion, Vanilla CSS, Axios
- **Backend**: Node.js, Express, Nodemailer
- **Database**: MongoDB (Atlas)
- **Deployment**: Vercel (Frontend), Render (Backend)
