# Portfolio Features Guide 🚀

This portfolio is not just a resume; it's a high-performance React application designed to showcase deep technical skills through gamification and immersive UI.

## 🌌 Experience Modes
1.  **Classic Portfolio**: A sleek, high-end professional layout with vibrant neon aesthetics, smooth scroll progress tracking, and refined typography.
2.  **Cyber Maze (Arcade Mode)**: A 60fps top-down game built with a custom React game engine.
    - **Symmetrical Grid Compiler**: Procedurally generates the Pac-Man style map from a string grid.
    - **Combat System**: Real-time shooting logic with bullet-wall and bullet-ghost collision.
    - **Smart Minimap**: Features a "Fog of War" illuminating system and real-time entity tracking.
    - **Multicast Sensors**: A live objective tracker that calculates directions (UP/DOWN/LEFT/RIGHT) to the next portfolio item.

## 🕹️ Built-in Arcade
Inside the game world, you can access the **Neon Arcade** featuring:
- **Typing Blitz**: A fast-paced tech-word typing trainer.
- **Memory Match**: A brain-trainer with tech-stack icons.
- **Tic-Tac-Toe**: vs a custom AI bot.
- **Pong & Snake**: Classic arcade staples with modern neon enhancements.
- **Car Racing**: A reflex-based dodge game.

## 🛠️ Technical Prowess
- **Custom Cursor Engine**: Lag-free custom follow-cursor with hover state detection.
- **3D Certificate Wall**: An interactive 3D space showcasing verified achievements.
- **Full-Stack Comms**: Integrated Node.js backend with Nodemailer for direct email notifications.
- **Responsive Architecture**: Fully adaptable from 4K monitors to small mobile devices.
